# Traffic Sign Quantization Robustness

Research code for evaluating traffic-sign classifiers under quantization and image corruption.

## Dataset

The real GTSRB images and annotations are included in `data/raw`. The benchmark website states that the data is free to use and requests citation of:

J. Stallkamp, M. Schlipsing, J. Salmen, and C. Igel. “The German Traffic Sign Recognition Benchmark: A multi-class classification competition.” *IEEE International Joint Conference on Neural Networks*, 2011.

Dataset details and downloads: [German Traffic Sign Benchmarks](https://benchmark.ini.rub.de/gtsrb_dataset.html).
